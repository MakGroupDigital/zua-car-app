# AUTONEX - Platform de Gestion Automobile

Application complète de vente, location de véhicules et gestion de pièces détachées avec dashboard admin professionnel, sécurité automobile, garages, stations-service et conseillers automobiles.

## 🚀 Fonctionnalités

- **Vente de véhicules** : Publier et rechercher des véhicules à vendre
- **Location de véhicules** : Louer ou mettre en location des véhicules
- **Pièces détachées** : Vendre et acheter des pièces automobiles
- **Sécurité automobile** : Système GPS avec abonnement mensuel
- **Garages** : Trouver les garages les plus proches avec navigation
- **Stations-service** : Localiser les stations-service avec itinéraire
- **Conseillers automobiles** : Contacter des conseillers experts
- **Messagerie** : Communication entre vendeurs et acheteurs
- **Favoris** : Sauvegarder vos offres préférées
- **Notifications** : Recevoir des notifications push pour les nouveaux messages
- **Système de notation** : Noter les offres de véhicules

## �‍💼 Dashboard Admin

Le dashboard admin professionnel offre une gestion complète de la plateforme :

### Gestion Utilisateurs
- Voir tous les utilisateurs avec leurs détails
- Filtrer par statut (actif, suspendu, banni)
- Suspendre ou bannir des utilisateurs
- Voir l'historique d'activité
- Exporter les données utilisateurs

### Approbations & Validations
- Approuver ou rejeter les nouveaux listings
- Gérer les documents requis
- Vérifier les détails des offres
- Système d'approbation multi-niveaux

### Signalements & Modération
- Gérer les signalements des utilisateurs
- Appliquer des actions (suspension, ban, avertissements)
- Historique complet des incidents
- Analyse des patterns de fraude

### Gestion Listings
- Afficher tous les listings actifs
- Filtrer par catégorie et statut
- Voir les statistiques de chaque listing (vues, favoris)
- Supprimer ou archiver les listings

### Finances & Transactions
- Dashboard des revenus et commissions
- Gestion des payouts
- Analyse des transactions par méthode de paiement
- Détection de fraude
- Rapports financiers détaillés

### Analytics & Comportement
- Analyse complète du comportement utilisateur
- Top recherches et catégories populaires
- Taux de conversion
- Graphiques de croissance
- Segmentation des utilisateurs

### Utilisateurs En Ligne
- Voir les utilisateurs connectés en temps réel
- Localisation et appareil utilisé
- Page en cours de consultation
- Durée de session
- Historique d'activité

### Audit Trail
- Journal complet de toutes les actions admin
- Traçabilité des modifications
- Filtres avancés
- Export de logs

### Monitoring Système
- Performance du serveur (CPU, mémoire, disque)
- État des services API
- Alertes système
- État de la base de données
- Uptime et latence

### Paramètres
- Configuration de la plateforme
- Gestion des commissions et frais
- Paramètres de sécurité
- Limites de upload
- Mode maintenance
